대량 초대용 개별 초대링크 생성
Supabase 기본 초대메일 대신 이메일별 초대링크를 생성합니다. @khug.or.kr 회사 이메일만 초대할 수 있으며, 생성된 링크는 해당 사용자에게 개별 전달하세요.
새 사용자의 초대/삭제는 Auth 관리자 권한이 필요한 작업이라 공개용 브라우저 키로 처리하지 않습니다. 현재 운영 방식대로 Supabase Dashboard의 Authentication → Users에서 초대하고, 여기서는 초대된 사용자의 표시명·역할·활성상태만 관리합니다.

계량 지표는 상세 팝업 대상이 아닙니다.
